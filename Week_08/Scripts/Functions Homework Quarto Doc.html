My hope is to create usable functions that I can plug my summer research data into, as I work on writing my thesis. I study community botany, and my research consists of reading field plots to determine relative plant species cover. This summer I read 50 plots in an area of Hawaii Volcanoes National Park that had been subjected to wildfire in 2000. In each rectangular 30x20m plot, I read three parallel transect lines bisecting the plot lengthwise, with each line spaced 5m apart. Along each transect line I would record vegetation presence by species at intervals of 1m, totalling 93 observation points per plot. At each point I would record any species intersecting the point. This meant multiple species could be logged at the same point. This transect information was then entered into a csv logging the specific plot point, species, and vegetation type, similar to the table below.

My first function is designed to just scan through the csv I enter, tally all of the Species Code counts, and spit out a list of the top ten most common species, which then renders a bar chart showing the ten most common species visually.

Show code 
SpeciesCounter <- function(data,column=Taxon_Code) {
  #Step 1: create dataframe for output. Function requires dataframe and a specific column to locate (in curly-curly). If no column selected, function defaults to taxon code
  top10 <- data |>
    #performs count of values in specified species column
    count({{column}},sort = TRUE) |>
    #takes the count object,creates a top 10 list, doesn't allow 10th place ties
    slice_max(n,n=10,with_ties = FALSE) 
  
  #Step 3: ggplot output
  #for x,take the flexible string from step 1 and reorder them from most-least numerous. For y-axis,scale values depending on count from n
  top10chart <- ggplot(top10,aes(x=reorder({{column}},-n),y=n))+
    geom_col(fill="grey")+
    labs(title = "Ten Most Common Species in Plot",
         x = "Taxon Code",
         y = "Count")+
    theme_minimal()+
    theme(axis.text.x = element_text(angle = 45, hjust = 1))
  
  print(top10chart)
  
  
    return(top10) #returns list of top 10 most common species
}

#create function to match overstory plot points with understory
Shady <- function(overstory_data,
                  understory_data,
                  overstory_column=Taxon_Code) {
  overstory_points <- overstory_data|>
    #this step filters out all the "NoCan" values (for no canopy)
    filter({{overstory_column}} !="NoCan")|>
    #select based on point ID, then drop duplicates
    select(Point_ID)|>
    distinct()
  
  #Inner join to understory dataset. Count all rows where Point_ID matches, then return a list of all the understory rows fitting the condition
  understory_points <- understory_data |>
    inner_join(overstory_points,by="Point_ID")
  
  return(understory_points)
}

As part of my plot reading, I also recorded whether a given point had overstory. This means I have two separate dataframes for overstory and understory, but with point IDs shared by both. I want a function that will take the overstory points dataframe, select only for points with canopy, then compare that list against the understory dataframe to isolate only understory species points located directly under canopy.
