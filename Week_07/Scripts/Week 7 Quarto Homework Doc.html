Now let’s make a nice pretty map with labels and a pleasing color scheme.

Show code 
#map with different colors for different cats, on a nice background
ggplot(literally_just_cornwall)+
  geom_sf(fill = "lightgrey",
          color = "black")+
  geom_sf(data = cats_uk_sf, aes(color = tag_id), size = 2, alpha = 0.7  )+labs(title = "The Wandering Cats of Cornwall",caption = "Data from tidytuesdayR package")+
  scale_color_discrete(type = "plasma",guide = "none")+
  theme(panel.background = element_rect(fill = "lightblue"),
        plot.title = element_text(size = 16,face = "bold"),
        plot.caption = element_text(size = 8,face = "italic"))

This map is unfortunately a mess. With over 100 cats tagged in the dataset, it’s impossible to get a color scale that shows each cat on the map. The resulting layout is highly confusing. To make something that is visually understandable, I am going to artificially condense the cats point dataset so it only filters the locations of eight individual cats.

Show code 
#use filter function on cat points data to select eight individual felines
just_eight_cats_from_cornwall <- cats_uk_sf |>
  filter(tag_id %in% c("Ares","Indie-Tag","Tigger-Tag","Balu-Tag","Coco","Alfie-Tag","Carrots-Tag","Friday"))

This code chunk above selects just eight kitties, much easier to visualize on a map display.

Show code 
#The same map as above with only the eight selected cats
ggplot(literally_just_cornwall)+
  geom_sf(fill = "lightgrey",
          color = "black")+
  geom_sf(data = just_eight_cats_from_cornwall, aes(color = tag_id), size = 2, alpha = 0.7  )+labs(title = "The Wandering Cats of Cornwall",
                              subtitle = "Map of Cornwall County,England",
                              caption = "Data from tidytuesdayR package")+
  scale_color_viridis_d(option = "turbo",name = "Cat Name",labels = c("Ares","Balu","Carrots","Coco","Friday","Alfie","Indie","Tigger"))+
  annotation_scale(location = "tl",
                   width_hint = 0.4)+
  annotation_north_arrow(location = "br")+
  theme(panel.background = element_rect(fill = "lightblue"),
        plot.title = element_text(size = 16,face = "bold"),
        plot.subtitle = element_text(size = 12),
        plot.caption = element_text(size = 8,face = "italic"))

The final map has a discernible legend, and the color scheme has been changed so the cat points are more distinct. Realistically, this dataset would be best projected at a city or even neighborhood level. Even within a small county, it is difficult to get more than just a general sense of where the cats are located.
